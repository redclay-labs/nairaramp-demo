### Context
In `lib/wallet.ts` and `lib/ramp.ts`, the demo currently only connects to the Freighter browser extension. The `@nairaramp/core` SDK exports `walletsKitSigner(kit)` (documented in `upstream/core-API.md`), which natively wraps `@creit.tech/stellar-wallets-kit` to support multi-wallet signers including Albedo, xBull, Hana, and WalletConnect. Adding support for StellarWalletsKit gives developers a complete reference implementation for multi-wallet apps.
