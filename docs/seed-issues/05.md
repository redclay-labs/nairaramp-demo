### Context
In `app/components/WalletPanel.tsx`, `app/components/DepositSection.tsx`, and `app/components/WithdrawSection.tsx`, components rely on basic inline styles that do not dynamically scale on mobile viewports (320px–375px). Buttons and input fields currently do not guarantee the 48px minimum touch target size recommended by WCAG 2.5.5, and long transaction hashes or Stellar public keys can overflow narrow screen widths.

- [ ] Ensure all interactive buttons (`Connect`, `Pay with Naira`, `Cash out`) and amount inputs have a minimum tap target height of 48px on mobile devices.

- [ ] Verify that UI spacing and borders remain visually aligned on desktop (1024px+), tablet (768px), and mobile (360px).
