### Context
The repository currently tests components exclusively in a Node/jsdom simulated DOM environment via Vitest. Browser-specific behaviors—such as Next.js client-side hydration, synchronous popup window opening (`window.open("", "nairaramp_anchor")`), and cross-window location redirects—are not validated within a real browser engine. Setting up Playwright tests validates the actual user journey in Chromium, WebKit, and Firefox.
