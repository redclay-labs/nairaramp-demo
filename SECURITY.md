# Security Policy

## Supported Versions

Only the current version of `nairaramp-demo` on branch `main` receives security updates.

| Version | Supported |
| --- | --- |
| 0.1.x | :white_check_mark: |
| < 0.1.x | :x: |

## Reporting a Vulnerability

Please report security issues privately via GitHub's Private Vulnerability Reporting on this repository.

Do NOT open public GitHub issues or discussions for security vulnerabilities.

### Scope Notice

`nairaramp-demo` is a demonstration application and quickstart sandbox.
- Underlying SDK, ramp logic, SEP protocols, cryptographic key handling, and transaction signing issues belong to [`nairaramp-core`](https://github.com/redclay-labs/nairaramp-core).
- React hook, timeline component, or PayWithNaira UI component issues belong to [`nairaramp-react`](https://github.com/redclay-labs/nairaramp-react).
